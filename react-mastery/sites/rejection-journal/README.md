# 再试一次 · 求职拒绝记录本

独立的静态网站，记录公司、岗位、拒绝日期、拒绝阶段和原因。只支持投递后被拒绝、面试后被拒绝；同一公司同一岗位只计一次，可编辑更新。默认目标为 100 次，界面不预置任何求职记录。

数据只保存在访问者当前浏览器的 localStorage，不传给网站服务器，不跨设备同步。支持 JSON 备份导出和导入；导入会保留现有记录，跳过重复岗位。更换浏览器或清理浏览器数据前应先导出备份。删除可在当前页面撤销。

运行 `npm run dev`，打开 `http://127.0.0.1:4330/`。`npm test` 验证数据约束、去重、导入、统计；`npm run build` 生成 `dist/`，不需要依赖安装。
