# 从容 · 个人能力训练场

独立、无构建步骤的中文网页应用。入口为 `dist/index.html`，用任意静态服务器托管 `dist/` 即可。无需 API Key。

## 第一版

- 清晰思考：8 道原创行测风格单选题，涵盖逻辑判断、加强削弱、排列、定义与类比，含逐项解析、作答统计及错题回练。
- 其他模块：6 个情境，覆盖沟通、压力恢复、幽默表达。
- 首次回答 → 规则提示 → 重试 → 收获和现实行动。
- 原回答草稿与事件复盘草稿自动保存。
- 本地成长记录、现实行动完成标记、JSON 导出、单条删除。
- 自适应桌面及手机布局。

清晰思考按预设正确答案判题；其他模块反馈为预设关键词规则。不调用 AI，不做人格或心理评估。所有用户输入通过文本转义后显示。数据仅保存在浏览器 localStorage 中，不跨设备同步。字体通过 Google Fonts 加载。

## 本地运行

`node server.mjs`，打开 http://127.0.0.1:4331。
